# AI-Supply-Chain-Risk-Forecaster-International

A lightweight project that forecasts supply chain risk levels across global regions using multilingual sentiment analysis, simple logistics indicators, and a clean Streamlit dashboard.

This project includes:

Automated mock data generation

Multilingual sentiment scoring

Feature engineering

Random Forest risk model

FastAPI backend

Streamlit dashboard

Full PowerShell setup and run instructions

-----------------------------------------------------------------------
Features:

Multilingual sentiment analysis using a transformer model

Region‑level risk scoring (Low / Medium / High)

Time‑series risk visualization

API endpoint for predictions

Clean, simple dashboard
